Executive Summary

The Library Management System is a REST API backend for managing library operations: cataloging books, registering users, tracking book issues and returns, and generating QR codes for books. It is designed for librarians and library staff who need a digital system to manage their book inventory and lending operations.

Who Is This For?

Librarians & Library Staff
Add and manage books in the catalog, register members, issue and return books, and generate QR codes for inventory management.
Library Administrators
Oversee the full library catalog, track book circulation, manage user memberships, and ensure inventory accuracy.

Core Value Proposition

  • Book Catalog Management — Add, filter, and search books by language with pagination support
  • User Registration — Register library members with membership IDs and contact information
  • Book Issue Tracking — Issue books to users and track return dates
  • QR Code Generation — Generate QR codes for books via external API for easy scanning and identification
  • JWT Authentication — Secure login with stateless JWT tokens for API access

Authentication & Security

JWT-based stateless authentication using Spring Security with Auth0 java-jwt library.

JWT Authentication Flow ▶ 
sequenceDiagram
  participant U as User
  participant F as JWTAuthenticationFilter
  participant UD as LibraryUserDetailService
  participant DB as MySQL (Login Table)
  participant H as SecurityHelper

  U->>F: POST /login (username + password)
  F->>UD: loadUserByUsername(username)
  UD->>DB: Query Login table
  DB-->>UD: LoginEntity
  UD->>UD: Verify password
  UD-->>F: LibraryUserPrincipal
  F->>H: generateToken(userDetails)
  H->>H: Sign JWT with HS256 secret
  H-->>F: JWT token string
  F-->>U: ResponseModel with token

Key Security Features

FeatureImplementation
JWT LibraryAuth0 java-jwt
Signing AlgorithmHMAC (HS256)
Authentication FilterJWTAuthenticationFilter — intercepts POST /login
Authorization FilterJWTAuthorizationFilter — validates JWT on all other requests
UserDetailsServiceLibraryUserDetailService — loads users from Login table
UserDetailsLibraryUserPrincipal — Java implementation of UserDetails
Security ConfigSecurityConfiguration — defines filter chain and permitAll rules
Session ManagementStateless (no server-side sessions)
Security Configuration ▶

The SecurityConfiguration class configures Spring Security with the following rules:

RuleDetails
Permit All/user/**, /books/**, and /login are accessible without authentication
Authentication FilterJWTAuthenticationFilter placed before UsernamePasswordAuthenticationFilter
Authorization FilterJWTAuthorizationFilter placed before ExceptionTranslationFilter
CORSCurrently not explicitly configured
CSRFDisabled (stateless API)

Note: All endpoints are currently permitAll(), meaning authentication is not enforced on any endpoint. The JWT filters are in place but the security rules do not restrict access.

Books Management

Full CRUD operations for the book catalog, including filtering, QR code generation, and book issue/return tracking.

BooksController Endpoints ▶
MethodEndpointPurposeRequest Body
POST /books/add Add a new book to the catalog AddBookModel (bookName, author, publication, language, location, numberOfCopies)
POST /books/issue Issue a book to a registered user BookIssueModel (userId, bookId)
POST /books/return Return a previously issued book BookIssueModel (userId, bookId)
GET /books/qrcode Generate QR code for a book Query param: bookId
GET /books/filterBooks Filter books by language with pagination Query params: language, page, size
BooksDbService Logic ▶

The BooksDbService handles all book-related business logic:

  • Add Book — Creates a new BooksEntity with timestamps and saves to MySQL
  • Issue Book — Creates a BookIssueEntity linking user to book with issue date
  • Return Book — Updates the BookIssueEntity with return date
  • QR Code — Calls external API at api.qrserver.com to generate QR code image
  • Filter Books — Paginated query filtering by language using Spring Data Pageable

User Management

User registration, profile management, and JWT login functionality.

UserController Endpoints ▶
MethodEndpointPurposeRequest Body
POST /user/add Register a new library member AddUserModel (firstName, lastName, phoneNumber, emailId, membershipId)
POST /login JWT login (handled by JWTAuthenticationFilter) LoginModel (username, password)
UserDbService Logic ▶

The UserDbService handles user-related business logic:

  • Add User — Creates a new UserEntity with auto-generated membership ID, timestamps, and saves to MySQL
  • Login — Credentials verified via LibraryUserDetailService which queries the Login table
  • JWT Token Generation — SecurityHelper generates a signed JWT with user claims
